Executive summary

Audit website for compliance with WCAG v 2.2 level AA

Scope of the evaluation

Product name
www.charliehill.org.uk
Product scope
All web content of the public website of Charlie Hill. Located at https://charliehill.org.uk
WCAG version
2.2
Conformance target
AA
Accessibility support baseline
- Automated Baselines: Axe-core CLI, Accessibility Insights for Web, and WAVE. - Screen Reader Testing: NVDA on Windows 11 (Chrome/Edge). - Manual Inspection: Full keyboard-only pathing, visible focus state checking, 400% browser zoom reflow validation, and high-contrast color contrast analysis via TPGi CCA.
Additional evaluation requirements
The evaluation will cover all views of the digital product, rather than a selected sample set only
